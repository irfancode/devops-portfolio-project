# 4-Week DevOps & Cloud Study Plan

## Week 1: Cloud Fundamentals & Containerization

| Day | Topic | Hands-On Task | Time |
|-----|-------|---------------|------|
| 1 | AWS Account Setup | Launch EC2, configure security groups, SSH access | 2h |
| 2 | S3 & Storage | Create buckets, set permissions, lifecycle policies | 2h |
| 3 | Docker Basics | Install Docker, run containers, learn commands | 2h |
| 4 | Dockerfile | Containerize Flask app, multi-stage build | 2h |
| 5 | Kubernetes Intro | Install Minikube, deploy first pod | 2h |
| 6 | K8s Services | Deploy app, expose via Service, check logs | 2h |
| 7 | Mini-Project | Flask API in Docker on K8s, push to Docker Hub | 3h |

## Week 2: Infrastructure as Code & CI/CD

| Day | Topic | Hands-On Task | Time |
|-----|-------|---------------|------|
| 1 | Terraform Basics | Install, write config for EC2 instance | 2h |
| 2 | Terraform Modules | Create VPC, subnets, security groups | 2h |
| 3 | CloudFormation | Deploy stack with EC2 + S3 | 2h |
| 4 | GitLab CI/CD | Create pipeline: build → test | 2h |
| 5 | Pipeline Deploy | Add deploy stage with Terraform | 2h |
| 6 | Jenkins | Create freestyle job, build/test/deploy | 2h |
| 7 | Mini-Project | Full CI/CD: Docker API → EC2 via GitLab + Terraform | 3h |

## Week 3: Scripting, Monitoring & Optimization

| Day | Topic | Hands-On Task | Time |
|-----|-------|---------------|------|
| 1 | Python + AWS | Script to interact with S3 (boto3) | 2h |
| 2 | Bash Scripting | Monitor CPU/memory on EC2 | 2h |
| 3 | Prometheus | Set up, scrape metrics from app | 2h |
| 4 | Grafana | Create dashboards from Prometheus data | 2h |
| 5 | Cost Explorer | Analyze AWS costs, find waste | 2h |
| 6 | Rightsizing | Resize instances, clean unused resources | 2h |
| 7 | Mini-Project | Automated alerts + Grafana visualization | 3h |

## Week 4: Architecture, Security & Interview Prep

| Day | Topic | Hands-On Task | Time |
|-----|-------|---------------|------|
| 1 | Architecture Design | Design scalable web app on AWS | 2h |
| 2 | IAM & Security | Implement least privilege, MFA | 2h |
| 3 | Advanced Terraform | Modular design, workspaces | 2h |
| 4 | Troubleshooting | Simulate failures, practice debugging | 2h |
| 5 | DevOps Culture | Study best practices, collaboration tools | 2h |
| 6 | Mock Interviews | Practice cloud design, scripting questions | 2h |
| 7 | Portfolio Complete | Finalize GitHub, docs, architecture diagrams | 3h |

## Daily Time-Boxed Schedule (2 Hours)

| Time | Activity |
|------|----------|
| 0-15 min | Review concepts/tutorial |
| 15-60 min | Hands-on lab/practice |
| 60-75 min | Break |
| 75-105 min | Apply to mini-project |
| 105-120 min | Document & commit to GitHub |

## Weekly Deliverables

- **Week 1**: Running Flask API in Docker on Kubernetes
- **Week 2**: Automated CI/CD pipeline deploying to AWS
- **Week 3**: Monitoring dashboards with alerting
- **Week 4**: Complete portfolio with documentation
